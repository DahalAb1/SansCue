# SansCue

SansCue is a conference MVP for the Bee track of the Build, Ship, Shape: Amazon Developer Hackathon.

## Status

This repository is initialized for submission work. It is not eligible for final submission yet because it does not contain a working application and does not yet use data recorded and processed through a Bee device or an Apple Watch running Bee software.

## Required Bee Track Proof

The final submission must show the project using Bee data at runtime to deliver value to a user. For SansCue, the intended proof is:

1. Capture speaker context from Bee data.
2. Generate a short audience question from that context.
3. Let an audience member respond.
4. Show the updated feedback on a speaker view.

Synthetic transcripts may be used during development, but they do not satisfy the Bee track requirement.
